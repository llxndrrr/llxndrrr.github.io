# LXNDR — Portofolio

Website portofolio pribadi: **Mahasiswa IT yang suka bikin aplikasi.**

**🔗 Kunjungi:** https://llxndrrr.github.io/

## Isi

- **Pembuka** dengan bola partikel 3D yang bergerak pelan (Three.js)
- **Tentang**: kalimat yang menyala kata demi kata saat di-scroll
- **Project**: [Catatan Uang](https://github.com/llxndrrr/catatan-uang) dan [Tugasku](https://github.com/llxndrrr/jadwal-tugas)
- **Toolkit** dan **Kontak**
- Warna latar berganti mulus dari ivory ke navy saat di-scroll

## Desain

Gaya clean dan mewah dengan aturan warna 60-30-10:
60% ivory `#F5F1EA`, 30% midnight navy `#121A2B`, 10% champagne gold `#B08D57`.
Huruf: Bodoni Moda dan Plus Jakarta Sans.

## Teknologi

- HTML, CSS, dan JavaScript murni, tanpa framework
- Three.js untuk bola partikel (dikunci dengan hash integritas)
- `@property` CSS untuk animasi warna latar
- Content-Security-Policy untuk keamanan
- Menghormati pengaturan "kurangi gerakan" di perangkat pengunjung
